# 🎮 Jogo da Velha

Projeto desenvolvido para a disciplina de **Algoritmo e Programação** do curso de **Engenharia Civil**.

## 📌 Objetivo

Desenvolver uma aplicação web simples utilizando conceitos fundamentais de programação, lógica computacional e manipulação de interface gráfica através de tecnologias web.

O projeto consiste em um jogo da velha interativo para dois jogadores, implementando regras clássicas do jogo, controle de turnos e verificação automática de vitória ou empate.

---

## 🚀 Funcionalidades

- ✅ Alternância automática entre jogadores (X e O)
- ✅ Verificação automática de vitória
- ✅ Identificação de empate
- ✅ Bloqueio do tabuleiro após término da partida
- ✅ Botão para iniciar uma nova rodada
- ✅ Interface responsiva utilizando Bootstrap
- ✅ Atualização dinâmica do status do jogo

## 🎯 Regras do Jogo

1. O jogo é disputado entre dois jogadores:
   - Jogador X
   - Jogador O

2. Os jogadores alternam suas jogadas.

3. Vence o jogador que completar:

- Uma linha horizontal
- Uma linha vertical
- Uma linha diagonal

4. Caso todas as casas sejam preenchidas sem vencedor, ocorre empate.
